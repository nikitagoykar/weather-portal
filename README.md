# 🌦️ FairyWeather – World Weather Portal

[![Live Demo](https://img.shields.io/badge/demo-online-green)](https://nikitagoykar.github.io/weather-portal/world.html)

FairyWeather is a simple, lightweight weather portal that lets you search and add cities to check their weather conditions.  
It’s built with **HTML, CSS, and JavaScript** and hosted on **GitHub Pages**.

---

## 🚀 Live Demo

👉 [FairyWeather Portal](https://nikitagoykar.github.io/weather-portal/world.html)

---

## ✨ Features

- 🗓️ Displays the current date
- 🔍 Search for a city and add it to the portal
- ✅ Shows success / error feedback (e.g., “City not found” or “Successfully added”)
- 🎨 Clean, minimal, responsive UI

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **API**: (Planned) Weather data integration using [OpenWeatherMap API](https://openweathermap.org/api)
- **Hosting**: GitHub Pages

---

## 📦 Setup & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/nikitagoykar/weather-portal.git
   cd weather-portal
   ```
2. Open the project in your browser:
`open world.html`
